# 公共基础

本目录是真机 task 与仿真 stage 的共同先修模块，可单独授课，也可嵌入两套实验。

## 学习目标

完成公共基础后，学生能够：

1. 区分机器人本体、感知、决策、执行与反馈环节。
2. 正确使用米、弧度、秒、Hz 与无符号轴值。
3. 解释四足机器人坐标系、关节顺序和正方向。
4. 理解 UDP 心跳、状态帧、超时与实时控制的关系。
5. 按安全检查表开展实验，并记录可复现的数据。
6. 用“现象—假设—验证—结论”的方法排查故障。

## 使用方式

- **真机方向**：先学公共基础，再进入 `real_robot/`。
- **仿真方向**：先学公共基础，再进入 `simulation/`。
- **联合方向**：用同一坐标系和记录模板对比仿真与真机，分析模型误差。

HTML 版本位于 [`html/index.html`](html/index.html)，可双击离线打开，打印时自动展开全部章节。
