# 坐标与单位

## 学习目标

- 正确读取机器人坐标系中的前后、左右和转向符号。
- 区分角度制与弧度制、线速度与角速度、物理量与协议轴值。
- 解释关节位置偏差和默认关节角在 RL 观测中的作用。
- 识别正负号、单位换算和缩放系数导致的控制错误。

## 建议学时

2 学时，包含一次坐标方向核对练习。

## 先修知识

向量、基础三角函数和 Python NumPy。

## 坐标系

课程默认遵循右手系。描述方向时必须同时说明参考系：

- `pos_world`：世界坐标系中的位置。
- `vel_body`：机体坐标系中的速度；前进通常读取第 0 分量。
- `rpy`：横滚、俯仰、偏航角。
- 视觉标定：X 向右、Y 向前，原点为机器人地面投影。

不要把“图像坐标向右”直接当成“机器人向右”。Homography 的作用正是把像素坐标转换到地面米制坐标。

## 单位与范围

| 量 | 课程常用单位 | 注意事项 |
|---|---|---|
| 长度 | m | 超声波阈值 1.0 m、1.3 m |
| 平面角 | rad 或 deg | Python 三角函数使用 rad |
| 线速度 | m/s | 停稳阈值绝对值 <0.02 |
| 角速度 | rad/s | 转向需先确认符号 |
| 频率 | Hz | 30 Hz 周期约 33.3 ms |
| 时间 | s | 超时、帧龄、稳定时间必须使用一致时钟 |

## 关节角与默认姿态

Lite3 有 12 个驱动关节。RL 部署课程按每条腿的 HipX、HipY、Knee 顺序构造 12 维向量，默认位置模式为：

```text
(0.0, -0.65, 1.3) 重复 4 次
```

关节位置偏差为：

```text
qpos - default_qpos
```

观测构造错误会直接改变策略输入，即使模型文件完全正确，也可能导致动作错误。

## 协议轴值

协议使用有符号 16 位轴值，速度与轴值之间需要缩放。课程中的前进、侧向、转向死区分别为：

```text
forward: 6553
lateral: 12553
yaw:     9553
```

死区不是“建议值”，而是固件行为边界。很小的后退命令若直接截断为 0，会导致机器人不后退；task12 因此把非零小输出至少推到 `deadzone + 1`。

## 教师演示

运行 task12 的 `--selfcheck`，展示反向后输出越过前进死区。再展示零值不会被补偿成死区，避免静止时蠕动。

## 学生活动

给定 `vx=-0.2 m/s`、`fwd_scale=20000`，手算原始轴值并提出安全补偿方法。使用 Python 验证结果。

## 验收标准

- 所有数值都带单位。
- 能解释世界坐标与机体坐标的区别。
- 能正确构造 12 维默认关节向量。
- 能说明为什么零轴值不能做死区补偿。
