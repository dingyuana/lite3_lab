# 仿真课程文档

## 课程入口

- 离线 HTML：[`html/index.html`](html/index.html)。双击打开，支持章节导航、哈希直达、移动端选章和打印全展开。
- Markdown 讲义：`仿真控制课程/`。共 6 章，约 3.6 万字。

## 使用与维护

- HTML 是单文件课程页，CSS、JavaScript 和 SVG 全部内联，不依赖网络。
- 打印时全部章节自动展开；浏览器打印预览可检查表格与代码块是否完整。
- `仿真控制课程/` 是讲义源目录；`build/` 保存图解配置，扫描数据仅作渲染临时产物；`html/` 保存生成结果。
- 修改讲义后应重新扫描并渲染 HTML，不要只编辑生成文件。
- ROS2 实验需要另外安装并 source ROS2 与 `drdds` 消息工作空间；pip 依赖不能替代 ROS2 环境。
- stage5 只发布点云和仿真真值，不执行建图、定位或回环。
