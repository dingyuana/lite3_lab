# task10 键盘与视频控制界面

## 运行

在 `motion` 目录运行：

```bash
python3 task10_gui.py
```

可通过 `--ip`、`--state-port` 和 `--video-url` 指定运动主机、状态监听端口和 RTSP 视频地址。默认视频地址为 `rtsp://192.168.1.120:8554/test?tcp`。

需要 Python Tkinter、OpenCV（`cv2`）和 Pillow；机器人状态解析复用 `lite3_common.py`。

## 控制

- 方向键按住时持续移动，松开即归零；Esc 或“停止运动”按钮归零。
- 空格在 `(1,0,0)` 稳定趴下时触发起立并准备低速移动模式；在运动就绪的站立状态触发趴下。
- 主界面的“步态切换”模块提供低/中/高速、正常/匍匐、抓地越障、通用越障和高踏步越障指令。切换仅允许在已确认的非 AI 移动模式站立状态下进行；程序先归零运动轴并确认停稳，再发送指令并等待状态帧确认。
- 主界面的“扬声器”模块可打开、关闭和查询扬声器；界面启动及开关操作后会查询状态，状态由 `0x11050f08` 上报帧更新。
- 趴下、姿态未确认、状态帧过期或运动模式未就绪时，方向键不会发出运动轴值。
- `robot_basic_state=98` 表示初始待机、运控程序尚未触发首次起立；它不是故障，也不能据此判断起立或回零已完成。按空格仅在电量高于 20% 时触发首次起立；低电量时拒绝起立。
- 回零按钮只在 `(1,0,0)` 或状态码 98 时发送 `0x21010C05`，并等待 `(17,0,0)` 后返回 `(1,0,0)`。
- 起立、趴下和低速步态的状态切换由后台线程完成，界面线程不等待机器人状态。
- 视频在独立线程读取；画面断流时自动重连。

## 防撞范围

- 前进仅在前方超声波距离有效且不小于 1 m 时允许。
- 后退仅在后方超声波距离有效且不小于 1 m 时允许；前方障碍不会拦截后退，反之亦然。
- 按需求，左右移动不做超声波拦截。前后超声波不能检测侧方障碍，侧移前须由操作员确认侧面空间。
- 任一方向状态数据过期时，所有移动轴归零。

主程序在 `task10_gui.py`；机器人状态、姿态切换与安全门控在 `task10_robot.py`；RTSP 接收在 `task10_video.py`。
