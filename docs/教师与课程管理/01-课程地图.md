# 课程地图

## 课程定位

本课程面向机器人工程、自动化、计算机等专业本科实训，围绕四足机器人的通信、状态机、运动控制、视觉跟踪、物理仿真、强化学习部署和 ROS2 接口展开。课程强调可复现实验、安全边界和工程证据，不以“演示成功一次”作为唯一目标。

## 培养目标

完成课程后，学生能够：

1. 描述四足机器人感知—决策—执行—反馈闭环。
2. 使用 UDP 协议读取状态并发送安全运动命令。
3. 根据姿态、步态和速度状态设计顺序控制流程。
4. 理解死区、帧龄、超时、看门狗和急停等实时安全概念。
5. 使用 PyBullet/MuJoCo 建立可重复实验。
6. 解释 RL 观测、动作缩放和 PD 力矩伺服。
7. 使用 ROS2 话题传递关节指令并识别数据前端与算法边界。
8. 记录实验、分析故障并提交可评价的证据。

## 模块关系

```text
公共基础
  ├── 真机 task：协议 → 状态机 → 轴控制 → GUI → 视觉跟随
  └── 仿真 stage：物理引擎 → RL 部署 → ROS2 → LiDAR 数据前端
```

联合课程中，公共基础提供统一坐标系、单位、安全和记录规范；真机与仿真分别验证硬件约束和算法正确性。

## 学时方案

### 方案 A：真机为主，48 学时

| 模块 | 学时 |
|---|---:|
| 公共基础 | 10 |
| task01~task03 通信与状态机 | 8 |
| task05~task09 运动与防撞 | 14 |
| task10/task12 GUI 与视觉跟踪 | 12 |
| 综合项目与考核 | 4 |

### 方案 B：仿真为主，48 学时

| 模块 | 学时 |
|---|---:|
| 公共基础 | 10 |
| stage1~stage2 物理仿真 | 12 |
| stage3 RL 部署 | 12 |
| stage3/4 ROS2 接口 | 8 |
| stage5 数据前端与综合项目 | 4 |
| 考核 | 2 |

### 方案 C：联合课程，64 学时

公共基础 10、真机 22、仿真 22、综合对比 6、考核 4。综合项目要求同一速度指令分别在仿真和真机执行，比较速度、姿态、延迟和失败条件。

## 先修与分组

建议先修 Python、线性代数和计算机网络基础。每组 3~4 人，角色轮换：安全员、操作员、记录员、分析员。真机操作员和安全员不能由同一人长期担任。

## 教学资源

- `shared/`：公共基础课程。
- `real_robot/`：真机代码、资源和回归测试。
- `simulation/`：仿真代码、模型定位和测试。
- `docs/`：本课程地图、教师指南和量规。
- HTML 课程页：支持离线阅读、章节直达和打印全展开。

## 验收原则

过程评价与结果评价并重。出现安全违规时，实操项目按安全门槛直接判定不合格；技术故障则根据记录、诊断和恢复过程给分。
