## 使用与维护

- HTML 是单文件课程页，CSS、JavaScript 和 SVG 全部内联，不依赖网络。
- 打印时全部章节自动展开；浏览器打印预览可检查表格与代码块是否完整。
- `真机控制课程/` 是讲义源目录；`build/` 保存图解配置，扫描数据仅作渲染临时产物；`html/` 保存生成结果。
- 修改讲义后应重新扫描并渲染 HTML，不要只编辑生成文件。
- 真机首次起立、转向和前进必须在悬挂或防跌倒条件下进行；讲义中的离线验证不能替代现场安全验收。
